# PandorasBox

PandorasBox port for the Shared runtime. Workspace location: `Mods/PandorasBox/`.

Projects:

- `Celeste.Mods.PandorasBox.csproj`

Repository dependencies: **Shared**. Prepare Shared resources using the [Tools README][tools-readme], then build the main project:

```powershell
dotnet build ./Mods/PandorasBox/Celeste.Mods.PandorasBox.csproj -c Release
```
